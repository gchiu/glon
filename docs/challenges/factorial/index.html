Factorial (recursive)

VERIFIED Verified with the pinned interpreter.

Compute n! for a nonnegative integer using recursive multiplication. 0! and 1! are the base cases; larger n multiplies n by factorial(n-1).

Glon source

;; fact.glon -- recursive factorial for nonnegative integers.
;;
;; Contract: n is a nonnegative integer.
;; 0! = 1 and 1! = 1. For n > 1, fact(n) = n * fact(n - 1).
;;
;; This is ordinary Glon: func, either, <=, -, *, and recursion.
;; It adds no primitive and does not change the interpreter.
factorial: func [n] [
    either <= n 1 [
        1
    ] [
        * n factorial - n 1
    ]
]

Known limitations

  • Accepts nonnegative integers only. Negative inputs are outside the contract and are not tested.
  • 0! through 19! are correct on the pinned native interpreter.
  • 20! is the first arithmetic overflow: mathematical 20! = 2432902008176640000, but Glon exits 0 and prints 127058998962946048. Glon does not signal integer overflow.
  • Later factorial values are wrapped/incorrect even when the process exits 0; they are not valid mathematical results.
  • Recursion also has an implementation limit: factorial 85 returns an already-overflowed 0, while factorial 86 fail-stops with return-stack exhaustion (exit 1). This resource limit is distinct from the earlier arithmetic overflow.
  • Machine fail-stops are not catchable SIN! values. No runtime change is made to bypass either limit.
