File Text Replacement (partial)

PARTIAL Execution results verified with the pinned interpreter; status reflects the implemented scope.

Partial implementation of the REBOL 2 Cookbook file text replacement program. The in-memory first-occurrence replacement is implemented in Glon; the file read/write round trip is blocked by missing host I/O.

Attribution. Original REBOL 2 Cookbook recipe 'Replace Text in a File' by Carl Sassenrath (archived recipe linked in the reference source pane). The partial Glon implementation is original for this challenge.

Complete operation blocked. Complete file operation cannot be reproduced with the pinned native `glon` CLI and published vocabulary. The CLI has no file read/write words; the WASM host has no filesystem; the desktop GLON_LIVE proof exposes an asynchronous fs-read request/reply but no general Glon file-write binding. No host-side replacement or file processing is substituted.

Host dependency: None available for complete operation. A future complete challenge would require documented Glon file read and write capabilities.

;; replace.glon -- replace ONLY the first occurrence of `old` with `new`.
;;
;; PARTIAL CHALLENGE IMPLEMENTATION.
;; This operates on an in-memory STRING! only. The published native Glon CLI
;; and language vocabulary do not expose file read/write operations, so the
;; original REBOL program's file round trip cannot be reproduced here.
;;
;; Requires the published optional strings-ext library (s/slice), loaded by the
;; challenge runner from vendor/strings-ext.glon before this source.

find-first: func [text pattern i text-len pat-len] [
    either > + i pat-len text-len [
        -1
    ] [
        either s/= s/slice text i pat-len pattern [
            i
        ] [
            find-first text pattern + i 1 text-len pat-len
        ]
    ]
]

replace-first: func [text old new] [
    index: find-first text old 0 s/length text s/length old
    either = index -1 [
        text
    ] [
        tail-start: + index s/length old
        s/+ s/+ s/slice text 0 index new s/slice text tail-start - s/length text tail-start
    ]
]

Known limitations

  • Only the in-memory string replacement is implemented and tested. The original four-line REBOL program's file read/write round trip is not reproduced.
  • The pinned native glon CLI treats arguments as Glon source files and exposes no file I/O vocabulary.
  • The browser/WASM host has no filesystem. The desktop proof exposes fs-read but no general Glon file-write binding.
  • The partial implementation uses the published optional strings-ext library (s/slice) plus s/+, s/= and s/length. The vendored strings-ext.glon is an exact copy from the pinned upstream commit.
  • No C, Python, shell or host-side text replacement is used. No language or runtime extension was added.
  • An empty search pattern is outside this challenge's tested contract.
