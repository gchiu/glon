;; gcd.glon -- Euclidean greatest common divisor by repeated subtraction.
;;
;; Contract: a and b are nonnegative integers.
;; Returns the greatest common divisor of a and b.
;;
;; This is ordinary Glon: func, either, =, >, -, and recursion.
;; It adds no primitive and does not change the interpreter.
gcd: func [a b] [
    either = b 0 [
        a
    ] [
        either = a 0 [
            b
        ] [
            either = a b [
                a
            ] [
                either > a b [
                    gcd - a b b
                ] [
                    gcd a - b a
                ]
            ]
        ]
    ]
]

Known limitations

  • Accepts nonnegative integers only. Negative inputs are outside the contract and are not tested.
  • Subtractive Euclid uses one recursive call per subtraction. With the pinned 64K interpreter, gcd(73,1) succeeds while gcd(74,1) fail-stops with return-stack exhaustion.
  • The fail-stop is a machine-level halt, not a SIN!, so judge cannot catch it.
  • The recursion limit is an implementation resource limit; it is not worked around by changing the runtime in this challenge.
